# Security Policy

## Supported versions
| Version | Supported |
|---|---|
| 1.0.x (1.21.1 Forge) | ✅ |

## Reporting a vulnerability
Это клиентский косметический мод для Minecraft. Несмотря на это, если вы нашли проблему безопасности (например, краш-эксплойт через сетевые пакеты `SyncEarsTailPacket`), сообщите:

1. Создайте issue в приватном режиме: GitHub → репозиторий → **Issues** → **New issue** → отметьте `This is a security report` (GitHub скроет его до рассмотрения).
2. Или напишите в README-ссылку на автора (https://www.youtube.com/@YellowFire).

Пожалуйста, **не публикуйте** детали уязвимости публично до исправления.

## Обработка
* Подтверждение: в течение 48 часов
* Патч в релизе: как можно быстрее (обычно 1–3 дня)
* После выпуска исправления детали раскрываются в CHANGELOG.md

## Аудит сети
Пакеты мода (сервер→клиент, клиент→сервер) содержат только косметические параметры (размеры, смещения, углы). Все значения валидируются и ограничиваются допустимыми диапазонами перед применением. Краш-вектор через невалидные значения не найден, но каждая новая версия проходит проверку диапазонов.
