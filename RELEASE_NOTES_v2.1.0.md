# Kinetic Ears & Tails 2.1.0 — независимый ребрендинг

Этот релиз очищает публичное оформление проекта от упоминаний стороннего канала и персонажей. Физика и проверенное игровое поведение версии 2.0.0 сохранены.

## Новое название

Проект теперь называется **Kinetic Ears & Tails**.

- Супер-объёмный пресет: **Ember Tuft / Огненные кисточки**
- Пресет с бантами: **Ribbon Cat / Кот с бантом**
- JAR: `KineticEarsTails-1.21.1-2.1.0.jar`
- Файлы редактора: `kinetic_template.png` и `kinetic_custom.png`

## Очистка проекта

- Удалены публичные упоминания стороннего канала и связанного персонажа.
- Обновлены игровое название, описания, авторство, README и CurseForge-текст.
- Java-код перенесён в независимый пакет `com.kinetic.earstails`.
- Основные классы моделей и точки входа получили нейтральные имена.
- Встроенные текстуры получили нейтральные имена файлов.

## Совместимость

Внутренний `modId`, namespace ресурсов и ключи переводов пока сохраняют legacy-значение `faradayears`. Это исключительно технические идентификаторы, необходимые, чтобы обновление не уничтожило сохранённые настройки игроков и не сломало сетевую совместимость с данными 2.0.0.

Minecraft 1.21.1, NeoForge 21.1.x, Java 21.
