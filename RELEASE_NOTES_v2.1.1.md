# Kinetic Ears & Tails 2.1.1 — мешочек исключён из релиза

Декоративный поясной мешочек был незавершённым прототипом и не должен был попасть в публичную версию.

## Изменения

- Вкладка мешочка убрана из меню настройки.
- Переход к мешочку убран из вкладки тела.
- Рендер мешочка принудительно отключён.
- Его вторичная физика и коллизии больше не запускаются.
- Старое сохранённое значение `ShowPouch` игнорируется и при следующем сохранении записывается как `false`.
- Упоминания мешочка удалены из игрового описания, README и страницы CurseForge.

Реализация сохранена в исходном коде за выключенным feature gate и в закомментированных блоках интерфейса для возможной будущей доработки. Остальная функциональность и физика хвоста 2.1.0 не изменялись.
