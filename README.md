# 🦊 Kinetic Ears & Tails (Independent Cosmetic Mod)

## ✨ Порт для Minecraft 1.21.1 + NeoForge 21.1

Независимый косметический мод с настраиваемыми 3D-ушами, физическими хвостами и редактором текстур для **Minecraft 1.21.1 (NeoForge 21.1.x, Java 21)**!

> Версия для Minecraft 1.19.2 (Forge) сохранена в ветке [`1.19.2-legacy`](../../tree/1.19.2-legacy).

---

## 🎮 Возможности

- **3D-ушки** (5 форм: уши с кисточками, кошачьи, лисьи, заячьи, медвежьи) с независимой физикой (ухо пригибается в низких помещениях и от стен!)
- **Физический хвост** (Verlet + PBD): 1–9 хвостов веером + ★ супер-объёмный плюшевый хвост и ✨ девятихвостая Кицунэ
  - **⚙ 2 режима физики** (переключаются кнопкой во вкладке «Хвост»): **Классика** — свободная Verlet/PBD-цепь, стелющаяся по земле; **Реалистичная** — продолжение позвоночника с угловыми пределами позвонков, распределённой массой тканей и ограниченными мышечными моментами без предписанной S-кривой
  - Постоянная гравитация (`-0.070` на земле / `-0.060` в воздухе) и настоящие коллизии с блоками (F3+B — зелёные хитбоксы!)
- **🎨 Кастомная текстура 64×64** (вкладка «Текстура»): единый лист ушек и хвоста, пиксельный редактор прямо в GUI с live-превью, загрузка `kinetic_custom.png` из папки игры, шаблон `kinetic_template.png`, ластик с прозрачностью (cutout)
  - 🏷 **«Поверхностный слой»-подсказка**: полупрозрачные подписи зон прямо на канвасе — какая область красит уши, какая хвост (верх = корень, низ = кончик), столбцы ушек подписаны формами
  - Индикатор текущего цвета и работающий ПКМ-ластик
- **Фигура/тело**: грудь, бёдра, атлетические плечи — с независимой jiggle-физикой каждого полушария, текстура сливается со скином (`texOffs(20,20) / (8,20) / (20,28)`)
- **GUI кастомизации** по клавише **V** с 3D-предпросмотром (ЛКМ — вращение, ПКМ — наклон/зум, СКМ — сдвиг)
- **Пиксельный редактор текстуры** прямо в GUI + шаблон `kinetic_template.png` (64×64)
- **Мультиплеер**: настройки синхронизируются между игроками, сохраняются за персонажем (переживают смерть)

## 📦 Установка (для игроков)

1. Установи **Minecraft 1.21.1**
2. Установи **NeoForge 21.1.x** (https://neoforged.net)
3. Скачай `KineticEarsTails-1.21.1-2.1.0.jar`
4. Положи jar в папку `.minecraft/mods/`
5. Запусти профиль NeoForge, нажми **V** в игре

## 🔧 Сборка (для разработчиков)

Требуется **JDK 21**.

```bash
# Windows
.\gradlew.bat build

# Linux / macOS
./gradlew build
```

Готовый jar появится в `build/libs/KineticEarsTails-1.21.1-2.1.0.jar`.
