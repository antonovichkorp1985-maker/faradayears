# Kinetic Ears & Tails v1.5.5 — реалистичная физика по умолчанию и понятный редактор UV

## Физика

- Для новых настроек режимом по умолчанию стала «Реалистичная» физика.
- Сброс настроек хвоста также выбирает реалистичный режим.
- Изменения несения из v1.5.4 отменены: скриншот с лежащим хвостом оказался тестом классического режима. Реалистичная конфигурация v1.5.3 уже работала правильно и сохранена без дополнительного подъёма.
- Ранее явно выбранный пользователем классический режим не перезаписывается при загрузке сохранения.

## Редактор текстуры

- Вместо ограниченного списка готовых цветов добавлен полноценный HSV-пикер.
- Верхнее поле выбирает насыщенность и яркость, нижняя радужная полоса — оттенок.
- На UV-листе появились наглядные контуры ушных зон и швы цилиндрической развёртки хвоста.
- Направление хвостовой развёртки и деление окружности теперь видны прямо поверх холста.
- Ластик и переключатель UV-подсказок сохранены.
