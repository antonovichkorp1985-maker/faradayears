## Description

# Kinetic Ears & Tails

Bring expressive, physically animated ears and tails to your Minecraft character.

**Kinetic Ears & Tails** is an independent cosmetic customization mod for Minecraft 1.21.1 and NeoForge. Create anything from a subtle pair of pointed ears and a slim tail to a super-volumetric plume or a full multi-tail fan—all configurable from an in-game editor with live 3D preview.

## Expressive 3D ears

- Several original ear shapes, including tufted, pointed, long and fluffy styles
- Independent left and right ear movement
- Reactions to nearby blocks and low ceilings
- Adjustable size, rotation and placement
- Debug hitboxes available through F3+B

## Physically simulated tails

- One tail or multi-tail configurations
- Slim, fluffy and super-volumetric profiles
- Adjustable length, width, taper and fan spread
- Gravity, inertia and collision with terrain
- Two selectable physics modes:
  - **Classic** — a loose Verlet/PBD chain
  - **Realistic** — a skeletal-muscular model with joint limits and distributed support
- A soft-tissue collision profile matched to the visible central volume of the tail
- The realistic mode does not force the tail into a fixed S-curve or a pre-authored raised arc

## In-game appearance editor

Press **V** by default to open the customization screen.

- Live 3D character preview
- HSV color picker
- 64×64 texture canvas
- UV guides for ears and the cylindrical tail unwrap
- Transparent eraser
- PNG import using `kinetic_custom.png`
- Exportable `kinetic_template.png`
- Ready-made presets such as **Ember Tuft**, **Ribbon Cat**, fox, wolf, rabbit and kitsune-inspired configurations

## Additional customization

- Optional body-shape controls
- Independent secondary-motion settings
- Optional animated decorative belt pouch
- Complete factory reset
- Persistent player settings

## Multiplayer

Appearance settings synchronize between players and persist with the character. For complete multiplayer functionality, install the mod on both the client and server.

## Requirements

- **Minecraft 1.21.1**
- **NeoForge 21.1.x**
- **Java 21**

No additional mods are required.

## Installation

1. Install NeoForge for Minecraft 1.21.1.
2. Download the Kinetic Ears & Tails JAR.
3. Place it in the `.minecraft/mods` folder.
4. Start the game and press **V**.
